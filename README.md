# Pan De Vida Website Version 3

This version is designed for easy iPad upload to GitHub.

## Important

All files belong in the root of the repository. There is no assets folder.

Upload these files together:

- index.html
- about.html
- new-here.html
- ministries.html
- events.html
- watch.html
- prayer.html
- giving.html
- contact.html
- thanks.html
- styles.css
- app.js

## Replace the current repository files

1. Open the `pan-de-vida-website` repository.
2. Delete the current HTML, CSS, and JavaScript files.
3. Upload every file from this folder.
4. Commit the changes.
5. GitHub Pages will rebuild automatically.

## Prayer form

Open `prayer.html` and replace:

`REPLACE-WITH-CHURCH-EMAIL`

with the approved church email address.
